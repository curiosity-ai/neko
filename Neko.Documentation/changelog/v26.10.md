# :icon-sparkles: Features

::: change {badge="New" title="API reference pages laid out like Microsoft Learn"}
`neko sync-api-docs` can now write a type's reference across several pages instead
of one `csharp-docs` block. Two markers on the type's page,
`<!-- api:type … -->` and `<!-- api:members … -->`, become the *Definition*
(namespace, assembly, package, source line), the declaration, *Inheritance* and
*Implements*, and the *Constructors*, *Properties*, *Methods*, *Events* and
*Fields* tables. Every member group gets its own page next to it, with an
*Overloads* table and *Parameters*, *Returns*, *Exceptions*, *Examples* and
*Remarks* per overload, read from the XML doc comments.

Hand-written content between the markers stays. Generated pages carry a comment
that marks them as generated, so a page for a member that was removed is deleted
on the next run and a hand-written page next to them is left alone. See
[`neko sync-api-docs`](/guides/cli#neko-sync-api-docs).
:::

::: change {badge="New" title="Scenes fit their narration"}
A video scene with no `duration` now lasts until every voice-over line anchored to
it (`at="scene-id+0.4"`, `scene-3`, or an element in it) has been spoken, plus
`tail` (0.8 s), before the next transition. Scenes are fitted in order, so a
longer scene moves every anchor after it and a narrated video needs no
hand-timed durations. `narration: fit: false` turns it off; `tail:` sets the
pause. See [Voice-over](/videos/voice-over.md#scenes-fit-their-narration).
:::

::: change {badge="New" title="A cursor can aim at a point in a screenshot"}
`::: cursor {on="screen" to="63.6%,12.9%"}` reads its points as percentages of the
screenshot in the scene's `browser` or `window` frame, as it is drawn, instead of
the scene. A click lands on the control it is aimed at however the frame is
sized. `on="#id"` measures against any element.
:::

# :icon-bug: Fixes

::: change {badge="Fixed" title="A catalog voice stays one speaker across the voice-over"}
`narration: voice: <catalog id>` used to hand only the voice's description to the
VoiceDesign model, which designs a new voice for every sentence, so the narrator
drifted from line to line. A catalog voice is now cloned from its reference
recording with the Base checkpoint (`Qwen/Qwen3-TTS-12Hz-1.7B-Base`), so every
sentence is the same speaker. The reference samples of the English catalog ship
with Neko (`Voxwerk.Voices.English.*` sample packages). `clone: false` brings back
the designed voice; `cloneModel:` picks another Base checkpoint. Takes made the old
way are keyed differently and are re-synthesized once.
:::

::: change {badge="Fixed" title="Screenshots in a browser, window or phone frame stand still and are not cropped"}
An image-only paragraph inside a frame took the default `zoom` entrance, so the
screenshot grew inside chrome that had already settled. It now arrives with its
frame. A `browser` or `window` holding one screenshot takes the screenshot's
proportions instead of stretching to the scene and cropping it with
`object-fit: cover`, and a screenshot written straight into the frame no longer
picks up the 40 px margin meant for Markdown screens. In the curiosity theme the
frame takes the scene's ground (`--card`), so a dark screenshot on an `ink` scene
sits in dark chrome.
:::

::: change {badge="Fixed" title="A figure's picture fits the slide in the curiosity deck"}
A `::: figure` image is sized to the slide's width, so a screenshot under a
heading ran off the fixed canvas and took its caption with it. Once the images of a
slide have loaded, a figure that overflows has its picture capped by the overflow,
keeping its proportions, on screen and in the PowerPoint export.
:::

::: change {badge="Fixed" title="A scene no longer leaves the moment its animation lands"}
A scene with a `duration` shorter than its content cut the content off: a swap
skipped its last word, and an animation that finished on the cut was never seen.
A scene with a `duration` that leaves less than a second after its last element
arrives (or less than its own `hold`) is now lengthened to that arrival plus
`hold`, with a warning. `hold="0"` keeps the written duration. See
[Holding the last state](/videos/video-structure.md#holding-the-last-state).
:::

::: change {badge="Fixed" title="Four or more stat cards in the curiosity theme"}
`::: stats {class="cards"}` styled three cards: a fourth sat at the top of the
row with no background. The stair now steps any number of cards over the same
180 px, and the colours cycle paper, deep blue, slate, ink.
:::
